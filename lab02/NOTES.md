# Лабораторная работа №2

## Состояния Git

### Рабочая папка

Рабочая папка — это файлы проекта, с которыми я сейчас работаю. Изменения в них ещё не обязательно сохранены в истории Git.

### Индекс

Индекс — это промежуточная область Git, в которую я добавляю изменения перед созданием коммита. Для добавления файлов в индекс используется команда `git add`.

### Коммит

Коммит — это сохранённое состояние проекта в истории Git. Каждый коммит содержит определённый набор изменений и сообщение, описывающее эти изменения.
